All notable changes to the `yukumo` Lavalink client library.

## v1.7.0 — 2026-08-06

### Added

- **Session Resuming Across Restarts** — `ManagerOptions.resuming` (`{ enabled, timeout = 60, persistPlayers = true }`). Session IDs persisted per node (`yukumo:session:<nodeId>`) and seeded pre-connect via `WebSocketClient.setSessionId()`; a restarted bot reclaims its Lavalink sessions and **audio keeps playing through the restart**. `NodeConfig.resuming` enables it per node (`Session-Id` header no longer requires `resumeKey`). → [Session Resuming](/docs/session-resuming)
- **Player Restore ("keep playing")** — with `resuming.persistPlayers`, every player persists a full snapshot (`yukumo:player:<guildId>` — queue, position, volume, filters, repeat/autoplay/24-7 flags; refreshed on trackStart, every playerUpdate ~5s, queue mutations, playback setters). `init()` runs `restorePlayers()`: a resumed session's live player is **adopted silently** (`adoptLiveState()` — no play request, zero audio gap); otherwise the bot rejoins voice and replays at the saved position. New `playerRestored (guildId, resumedLive)` event; `Player.saveState()` / `restoreFromState()` / `enableStatePersistence()`. `YuKumo.destroy()` flushes final snapshots.
- **Source-Aware Autoplay (all sources)** — `Player.resolveAutoplayTrack()` picks per-source strategies: YouTube/YT Music RD mix, Spotify `sprec:seed_tracks=`, Deezer `dzrec:`, Yandex `ymrec:`, SoundCloud `/recommended`, then `scsearch`/`amsearch`/`ytsearch` fallbacks on artist + title. Recently played tracks excluded. `playerDefaults.autoplay` enables autoplay on every created player; custom `autoplayFetcher` still overrides. → [Autoplay & Utilities](/docs/autoplay-and-utilities)
- **NodeLink Support** — auto-detected from `/v4/info` (`isNodelink`) or forced via `NodeConfig.isNodeLink`; `node.isNodeLink` / `player.isOnNodeLink`. Session resuming automatically skipped on NodeLink (unsupported there). `getLyrics()` routes to NodeLink's built-in `/v4/loadlyrics`. NodeLink SponsorBlock event names map to `segmentsLoaded`/`segmentSkipped`. → [NodeLink Support](/docs/nodelink)
- **NodeLink Extra Features**:
  - REST: `loadLyrics(encoded, lang?)`, `loadChapters(encoded)`, `getMeaning(encoded)`, `getConnectionMetrics()`, mixer CRUD (`addMixLayer` / `getMixLayers` / `updateMixLayer` / `removeMixLayer`).
  - Player: `getNodeLinkLyrics(lang?)`, `getChapters()`, `getTrackMeaning()`, `setGaplessNext(track | null)`, `setFading({ trackStart | trackEnd | trackStop | seek | ducking })` (curves: linear, exponential, logarithmic, s-curve), mixer helpers.
  - Voice receive: `NodeLinkVoiceReceiver` (`node.createVoiceReceiver(guildId)` / `player.createVoiceReceiver()`) — `/connection/data` WebSocket, `startSpeaking` / `endSpeaking` events with base64 opus/pcm audio.
  - Events: `mixStarted` / `mixEnded`. `updatePlayer()` accepts `nextTrack`, `fading`, `track.audioTrackId`.
- `LavalinkInfo` gains `isNodelink` / `node` fields.
- **DX Utilities**:
  - `player.waitUntilPlaying(timeoutMs = 15000)` — resolves when the track actually starts; immediate when already playing; rejects on destroy/timeout.
  - `player.isVoiceReady` getter — pairs with `waitForVoiceReady()`.
  - `queue.lock(fn)` — promise-chain mutex for multi-step queue edits; `queue.isLocked` getter.
  - `queue.unique(keyFn?)` — dedupe (default key `encoded` → `info.identifier`), keeps first occurrence, never removes the playing track.
  - `players.find(criteria)` / `players.findOne(criteria)` / `kumo.findPlayers(criteria)` — filter by `node`, `status`, `voiceChannelId`, `textChannelId`, `autoplay`, `stayInVc`, `playing`, custom `filter`.
  - **Node maintenance mode** — `node.setMaintenance(true)` drains a node (no new players, existing keep playing); `node.maintenance`, `node.drain(timeoutMs?, pollMs?)`.
  - `player.cache` — per-player `TTLCache` with auto-expiring entries (`cache.set("vote", true, 60_000)`); lazy expiry, cleared on destroy; `TTLCache` exported.
  - `kumo.broadcast(fn, criteria?)` — operation across all/matched players via `Promise.allSettled`.

### Changed

- `pause()`, `resume()`, `setVolume()`, `setLoop()`, `setAutoplay()` schedule a state snapshot when state persistence is on.
- Queue persistence and state persistence share the `Queue.onChanged` hook.

## v1.6.0 — 2026-08-04

### Added

- **Queue Persistence** — `queueOptions.persist` auto-saves every queue to the configured `StorageAdapter` (microtask-coalesced) and restores it on `createPlayer()`. Kept on shutdown (`DisconnectAllNodes`), deleted on normal destroys. `Player.enableQueuePersistence()` / `Player.restoreQueue()`, `Queue.onChanged` hook.
- **WebSocket Heartbeat** — ping/pong dead-connection detection per node (`enableHeartbeat`, `heartbeatIntervalMs` = 30000, `heartbeatTimeoutMs` = 10000). Half-open sockets terminated and reconnected; `ws.isAlive` getter.
- **SponsorBlock Plugin Integration** — `player.setSponsorBlock(categories)` / `getSponsorBlock()` / `deleteSponsorBlock()` plus `segmentsLoaded`, `segmentSkipped`, `chaptersLoaded`, `chapterStarted` events.
- **Live Lyrics (LavaLyrics)** — `player.getCurrentLyrics()`, `subscribeLyrics()`, `unsubscribeLyrics()` plus `lyricsFound`, `lyricsNotFound`, `lyricsLine` events.
- **Play Options** — `play()` / `playTrack()` accept `{ position, endTime, noReplace, paused, volume }`.
- **Player Protections** (`ManagerOptions.playerDefaults`) — `maxErrorsPerTime` sliding-window error-rate destroy (`{ threshold: 35000, maxAmount: 3 }`), `minAutoPlayMs` autoplay error-spam guard (10000ms), `queueEmptyDestroyMs` destroy-after-queue-end timer.
- **Destroy Reasons** — `DestroyReasons` enum; `destroy(reason)` everywhere; `playerDestroy` emits `(guildId, reason)`.
- **Link Policy** — `linksAllowed`, `linksWhitelist`, `linksBlacklist` (substring or RegExp) gate URL queries in `search()`.
- **Custom HTTP Headers** — `ManagerOptions.httpHeaders` (global) and `NodeConfig.httpHeaders` (per node) on REST + WS handshake.
- **Player API** — `toJSON()`, `ping` getter `{ ws, lavalink }`, `moveNode(nodeId?)` least-loaded auto-pick.
- **Queue API** — `sortBy("duration" | "title" | "author" | comparator, order)`, `removeTrack(track | tracks | predicate)`.
- **Filters** — `setAudioOutput("mono" | "stereo" | "left" | "right")` presets (`AudioOutputs` export).
- **Custom Player Class** — `ManagerOptions.playerClass`.
- **Utils** — `parseLavalinkConnUrl("lavalink://name:pass@host:port")`.

### Fixed

- Player leak: direct `player.destroy()` now unregisters from `PlayerManager` and decrements `node.playerCount`.
- Race: track-end handling (natural end / stuck / skip) serialized — no more double queue-advances.
- `position` interpolates between `playerUpdate` frames (clamped to track length); `seek()` clamps to `[0, length]`.
- `resume()` on an idle player no longer fakes `"playing"`; `pause()`/`resume()` idempotent.
- `setVolume()` remembered while the node session is down; applied on next play.
- `skip()` with nothing playing no longer crashes the autoplay path.
- Empty-VC and queue-empty timers `unref()`ed — no longer keep the process alive.

## v1.4.0 — 2026-08-01

### Added

- **Smart Autoplay Engine** — `setAutoplay(enabled, fetcher?)`, `isAutoplayEnabled()`, `autoplayTrackAdded` event.
- **Extended Queue Operations** — `Queue.swap(indexA, indexB)`, `Queue.skipTo(index)`, `Queue.removeRange(start, count)`, `Queue.clearExceptCurrent()`.
- **Audio DSP Presets** — `setSlowedReverb()`, `set3DAudio()`, `setPitchShift()`, `setVoiceIsolation()`, custom preset registry (`FilterChain.registerPreset()` & `applyPreset()`).
- **Smart Voice Channel Behaviors** — 24/7 mode (`stayInVc`), empty-VC monitor (`setVcMemberCount()`) with auto-pause / auto-disconnect timeouts.
- **Synced Lyrics & SponsorBlock** — `getSyncedLyrics()` via LRCLIB with `parseLrc()` timestamp parser; `SponsorBlockClient` segment auto-skip.
- **DX & UI Helpers** — `getProgressBar()`, `formatDuration()`, `createQueueEmbedData()`, `MiddlewareRegistry` hooks (`useBeforeTrackStart`).

### Fixed

- Voice connection handshake race: added `waitForVoiceReady()` promise.
- Session resumption on WS reconnect: re-sends OP4 voice credentials and player states.
- Auto-reconnect on Discord voice close codes 4009 / 4015 (`WebSocketClosedEvent`).
- Voice endpoint handling: active endpoint preserved when `null` endpoints arrive during Discord region failovers.
