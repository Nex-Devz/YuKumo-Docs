## Versioning

YuKumo follows [semantic versioning](https://semver.org). Minor releases (`1.x.0`) add features and stay backwards compatible; patch releases fix bugs. Install a specific version with:

```bash
npm install yukumo@1.7.0
```

The raw changelog also ships inside the npm package as [`CHANGELOG.md`](https://github.com/Nex-Devz/YuKumo/blob/master/CHANGELOG.md).
